# Cursor Landing Page

This project is a static landing page inspired by Cursor's website. It was built as part of a ChaiCode peer review assignment using plain HTML and CSS.

## Project Files

- `index.html` contains the page structure.
- `style.css` contains the styling and layout.
- `assets/` contains images and SVG assets used by the page.

## How to View

Open `index.html` in a browser to preview the page locally.
